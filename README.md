# Responsive Travel Website

## Overview

Responsive Travel Website is a modern frontend web application developed using HTML, CSS, and JavaScript. The project is designed to promote beautiful travel destinations with an attractive, responsive, and user-friendly interface. It provides visitors with an engaging browsing experience through smooth scrolling animations, interactive sections, and a visually appealing layout that adapts seamlessly across desktop, tablet, and mobile devices.

The website includes multiple travel destination sections, an elegant navigation system, dark and light mode support, and modern UI components to enhance usability. This project helped me strengthen my skills in responsive web development, JavaScript interactions, CSS animations, and creating aesthetically pleasing web interfaces.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Modern and attractive user interface
- Beautiful travel destination showcase
- Smooth scrolling animations
- Dark and light mode toggle
- Interactive navigation menu
- Optimized layout using Flexbox and Grid
- Clean and organized code structure
